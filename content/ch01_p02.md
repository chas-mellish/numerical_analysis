# Chapter 1, Program 2: Bairstow quadratic factors

*Book pages 25–26, "Solution of Nonlinear Equations". Catalog entry: `catalog/ch01_p02_bairstow.toml`.*

## The method

Bairstow's method finds the real **quadratic factors** of a real polynomial. Complex roots come in
conjugate pairs, and each pair is the root pair of one real quadratic, so no complex arithmetic is
needed. Gerald's program handles polynomials of degree 2 to 6.

Dividing the polynomial a₀xⁿ + … + aₙ by a trial quadratic x² − r·x − s leaves a remainder
b₍ₙ₋₁₎(x − r) + bₙ. Both remainder terms depend on r and s, and the method drives them to zero with
Newton's method in two variables:

1. **Synthetic division.** `B(J) = A(J) + R*B(J-1) + S*B(J-2)` for J = 3 … 9. The last two B values
   (B(8), B(9)) are the remainder.
2. **Partial derivatives.** The same recurrence applied to the B's,
   `C(J) = B(J) + R*C(J-1) + S*C(J-2)`, gives the derivatives of the remainder with respect to r and s.
3. **Newton correction.** With `DENOM = C(7)*C(7) - C(8)*C(6)`,
   `DELR = (-B(8)*C(7) + C(6)*B(9))/DENOM` and `DELS = (-C(7)*B(9) + B(8)*C(8))/DENOM`; then
   R = R + DELR and S = S + DELS.
4. **Test.** The factor is accepted when |DELR| + |DELS| ≤ TEST. Otherwise the program repeats from
   step 1, at most LIM times for this factor.
5. **Deflation.** The quotient B(3) … B(7) becomes the new polynomial (`A(K) = B(K-2)`), the degree
   drops by 2, and the next search **starts from the R and S just found**. When the degree reaches
   2 the program prints the remaining quotient as a final quadratic (FORMAT 22). When it reaches 1
   it prints a final linear factor (FORMAT 23).

The subscripts are advanced by 2 so that B(1) = B(2) = C(1) = C(2) = 0 let the first two terms use the
same recurrence as the rest. Convergence is quadratic once R and S are close. The last corrections of
the book's run shrink from 4e-3 to 2e-5 to 1e-9.

**The sign convention.** FORMAT 17 prints each factor as `X**2 + R X + S`, but the recurrence divides
by **x² − r·x − s**. This is an original quirk, confirmed by the book's own text. The printed lines
`X**2 + 4.19999 X + -2.09999` and `X**2 + 3.29999 X + -6.20000` are the exact factors
x² − 4.2x + 2.1 and x² − 3.3x + 6.2. Run with `--verbose` (or the "verbose" option in the UI) to see
the true factors and their roots.

## The book's data cards

Card 1 (`FORMAT (7F10.0)`) holds the coefficients of X⁶ down to X⁰. Card 2
(`FORMAT (2F10.0, E10.0, 2I3)`) holds R1, S1, TEST, LIM and N:

```
0.        1.        -17.8     99.41     -261.218  352.611   -134.106
0.        0.        1.E-5     20  5
```

This is x⁵ − 17.8x⁴ + 99.41x³ − 261.218x² + 352.611x − 134.106 (degree 5, so the X⁶ coefficient is
0). The search starts from R = S = 0, accepts a factor when |DELR| + |DELS| ≤ 10⁻⁵, and allows 20
corrections per factor. The book's output (the heading `DEMONSTRATION PROGRAM OUTPUT` was printed at
the top of a new page):

```
THE ORIGINAL POLYNOMIAL-

    POWER OF X     COEFFICIENT

          5           1.00000
          4         -17.80000
          3          99.41000
          2        -261.21800
          1         352.61100
          0        -134.10600


THE QUADRATIC FACTORS ARE-

X**2 +    4.19999 X +   -2.09999
X**2 +    3.29999 X +   -6.20000
   1.00000X +  -10.30000
```

The exact factors are (x² − 4.2x + 2.1)(x² − 3.3x + 6.2)(x − 10.3). The roots are 3.619868 and
0.580132, the complex pair 1.65 ± 1.864806i, and 10.3. The first factor needs 8 corrections from
R = S = 0, and the second needs 5 more from the first factor's R and S (13 in total). The book does
not print the iteration count; it is shown in the trace.

## Other outcomes the program handles

| Situation | Book output | Modern behaviour |
|---|---|---|
| DENOM is exactly zero | none (the original loops forever, see errata) | R and S are bumped by 1, KOUNT restarts; `nudges` counts it |
| DENOM stays zero after more than LIM nudges | (no equivalent) | `DOES NOT CONVERGE AFTER  LIM ITERATIONS` (`NON_CONVERGENT`) |
| A factor needs more than LIM corrections | `DOES NOT CONVERGE AFTER   20 ITERATIONS` (FORMAT 24) after the factors already found | `NonConvergenceError` (`NON_CONVERGENT`) |
| N = 2 | the polynomial itself, then `.00000X + A` (the constant quotient) | same, kept as an original quirk |
| N = 4 or 6 | final quadratic, FORMAT 22 `A2X**2 + A1X + A0` | `final_quadratic` factor |
| N = 3 or 5 | final linear, FORMAT 23 `A1X + A0` | `linear` factor |
| N outside 2 … 6, or a nonzero coefficient above Xᴺ | (no check: wrong subscripts or a wrong polynomial) | `DegreeError` (`DEGREE`) |

**About the zero-denominator test.** The original tests `DENOM` with an arithmetic IF, so only an
exact zero takes the nudge branch. The modern code keeps that exact test. The earlier rewrite used
`|DENOM| < epsilon`. An exact zero is easy to hit: starting from R = S = 0, every C(J) equals A(J), so
DENOM = A(7)² − A(8)·A(6). That is zero whenever the x² coefficient and one of its neighbours are
zero, for example x⁴ − 16 or x³ − 8.

## Precision

The book ran in single precision on a machine that **chopped** printed digits. The exact factor
coefficient 4.2, computed as 4.1999998…, printed as `4.19999`. The modern drivers print the factor
lines with the RZ (round toward zero) edit mode, so the same kind of digits appear. The last digit
then depends on which side of the exact value the arithmetic lands:

| | factor 1 | factor 2 | linear |
|---|---|---|---|
| book | 4.19999 −2.09999 | 3.29999 −6.20000 | 1.00000 −10.30000 |
| real64 | 4.19999 −2.09999 | 3.30000 −6.20000 | 1.00000 −10.30000 |
| real32 (`SINGLE`) | 4.20000 −2.10000 | 3.29999 −6.19999 | 1.00000 −10.29999 |

Every value is within 2e-5 of the book's digits, and both precisions need the same 8 + 5
corrections. The golden tests compare numbers (within 2e-5, and within 1e-8 of the exact factors in
real64), not text. The echoed coefficients are rounded to nearest rather than chopped. The book
prints 99.41000, −17.80000 and −261.21800, exact as on a decimal machine, but binary 99.41 is
99.40999…, which would chop to `99.40999`. This echo is one of the hints that Chapter 1 ran on a
decimal machine; the book's computer is not identified (see `docs/architecture.md`, "The book's
computer").
